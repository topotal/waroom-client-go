## [v0.0.6](https://github.com/topotal/waroom-client-go/compare/v0.0.5...v0.0.6) - 2026-11-24

### ⚠️ BREAKING CHANGES

The bundled API spec is synced to version 0.2.0, which replaces `team_call_mode` on on-call escalation policies with `call_depth` and `call_traversal` (#198).

- Removed: the `TeamCallMode` field on `OnCallEscalationPolicy` and on the `OnCallEscalationPolicies` Create / Update requests and responses.
- Removed: the `CreateOnCallEscalationPolicyTeamCallMode` and `UpdateOnCallEscalationPolicyTeamCallMode` types.
- Added: the `CallDepth` field (how many people from the on-duty member to call in each step's team, 1–10; null means the whole team) and the `CallTraversal` field (`depth_first` or `breadth_first`), plus the `CreateOnCallEscalationPolicyCallTraversal` and `UpdateOnCallEscalationPolicyCallTraversal` types.

Migration:

| Before (`TeamCallMode`) | After |
| --- | --- |
| `all_members` | `CallDepth` null (unlimited) + `CallTraversal` `depth_first` (the default) |
| `on_duty_only` | `CallDepth` `1` |

```go
// Before
req.TeamCallMode.SetTo("on_duty_only")

// After
req.CallDepth.SetTo(1)
```

### Added

- `waroom.APISpecVersion`, the version of the API spec the library was built with (#202).
- `SimultaneousCallUsers` on the entries returned by `OnCallEscalationPolicies.GetSchedule` (API spec 0.2.0).

## [v0.0.1-alpha](https://github.com/topotal/waroom-client-go/compare/v0.0.0-alpha...v0.0.1-alpha) - 2026-11-18

First release of the Go client library for the Waroom API.

### Features

- Client built on the published Waroom public API spec (OpenAPI 3.1), with each resource exposed as a service field (e.g. `client.Incidents.List(ctx, ...)`).
- Supported services: `Incidents`, `Services`, `Labels`, `ActionItems`, `Runbooks`, `RunbookRules`, `Postmortems`, `PostmortemTemplates`, `IncidentDescriptionTemplate`, `WebhookConfigurations`, `Users`.
- API key authentication via the `WithAPIKey` option or the `WAROOM_API_KEY` environment variable.
- `APIError` type for server-side API errors, carrying the status code and error messages.
- Client options: `WithBaseURL`, `WithHTTPClient`, `WithUserAgent`, `WithRequestDump`, `WithResponseDump`.
